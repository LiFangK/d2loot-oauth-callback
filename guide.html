D2 LOOT TOOL / GET STARTED

绑定账号，只需三步

软件已经准备好连接信息。你只需要登录自己的 Bungie 账号并授权读取库存，无需申请 API、填写网址或复制令牌。

查看绑定步骤 ↓

  1. 在软件中点击绑定

    解压整个发布包，打开 D2LootTool.exe。点击主窗口的 设置 → 绑定 Bungie 账号，系统浏览器会打开 Bungie 官方授权页面。绑定期间保持软件运行。

  2. 登录并允许读取库存

    选择与你的 Destiny 2 账号关联的平台，例如 Steam、PlayStation 或 Xbox，完成官方登录。核对应用名称 D2LootTool，允许读取 Destiny 库存和仓库。

    登录在官方网页完成，软件内无需输入游戏密码。

  3. 允许浏览器返回软件

    授权后，网页会尝试打开 D2 Loot Tool。在浏览器提示中点击 打开 / 允许。如果没有自动返回，点击网页上的 返回 D2 Loot Tool。

    回到软件后等待首次同步。若出现多个独立游戏账号，在主窗口选择要监测的平台；跨平台存档会优先采用有效主账号。

首次同步不会弹出旧装备。

软件会先记录现有库存，之后定期检查新获得的装备。新武器进入通知队列，护甲只进入最近装备列表。官方数据同步可能有延迟。

遇到问题时

网页没有自动打开软件？

保持软件开启，点击回调页面的“返回 D2 Loot Tool”，允许浏览器打开应用。仍无法返回时，回到主窗口点击“取消连接”，再进入设置重新绑定。

关闭了授权网页，或者登录超时？

主窗口的“再次打开授权页”可继续当前连接。十分钟内没有完成会结束请求；之后从设置重新绑定即可。

重启软件后还需要登录吗？

设置中显示“自动续期已启用”的新版会加密保存登录，重启后自动恢复，短期授权到期时自动续期。网络暂时不可用会等待重试；长期授权失效或你撤销权限时，才需要在设置中重新绑定。旧版短期登录仍需重启后重新授权。

怎样解除绑定？登录信息保存在哪里？

点击设置 → 解除绑定，删除本机长期登录凭证，并尝试删除该设备的授权服务会话；库存历史仍保留。本机凭证由 Windows 用户加密保护，服务端加密保存续期令牌，游戏密码不会交给本工具。完整撤销本应用的 Bungie 权限请到 Bungie 账号设置处理。

是否需要 DIM 账号？会改动装备吗？

无需登录 DIM。装备推荐使用公开的 DIM Wishlist 数据；本工具只读取库存，不转移、装备、锁定或分解物品。

绑定成功但没有新装备？

首次同步后，只有新发现的装备才会出现。可以点击“刷新”检查，留意主窗口的网络或授权提示。请确认所选平台有你的 Destiny 2 角色。
